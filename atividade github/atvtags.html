O que são Tags html Para que servem as TAGs (a), (p), (mark) e (H- 1, 2, 3, 4, 5, 6)?

as TAGs HTML são os códigos para criar comandos dentro do site como por exemplo.

sobre
  • A tag "a" Serve como uma tag "âncora", é a que coloca um link no site dentro do código ele pede a URL do link e depois o nome que queremos para personalizar o link
  • A tag "p" atua apenas para colocar um parágrafo no texto
  • a tag "mark" pode ser utilizada em qualquer tipo de texto dentro do site e serve para dar um destaque á palavra ou oração colocando uma marcação nela
  • A tag (H) Pode ser utilizada seguida dos numeros 1, 2 ,3, 4 , 5, 6 sendo 1 com mais enfÂse descendo proporcionalmente até o 6

Quais são as tags CSS "display-flex", "background-color" e "gap" e o que são as tags sêmanticas do HTML

As tags sêmanticas do HTML são usadas pela tag "class" que cria um nome para as tags, para serem personalizadas dentro do CSS

  • Display-flex, muda a ordem em que o site é colocado mudando de colunas para linhas ficando um do lado do outro.
  • "background-color" É usado para mudar a cor de fundo da tag selecionada
  • O "gap" pode ser visto como uma brecha entre os container, podendo personalizar o espaçamento entre eles
